# Apartments.com

> Apartments.com is the largest United States rental-listings marketplace, owned by CoStar Group and operated from Arlington, Virginia as the anchor of the Apartments.com Network (ApartmentFinder.com, ApartmentHomeLiving.com, ForRent.com, ForRentUniversity.com, WestsideRentals.com, Apartamentos.com, After55.com, CorporateHousing.com). It is an Internet Listing Service: owners and property managers buy advertising, their inventory flows IN from property management systems, and leads flow back OUT to the advertiser's CRM.

> API posture: CLOSED. There is no developer portal, no OpenAPI/Swagger, no OData $metadata, no GraphQL schema, no AsyncAPI, no webhooks, no SDK, no CLI and no Postman collection. developer/developers/docs/partners/feeds/data.apartments.com do not resolve in DNS; api.apartments.com resolves only to the same Akamai edge as www and returns HTTP 403 to every non-browser request, robots.txt included. Apartments.com is NOT RESO-certified — it appears nowhere in the RESO certificates list and its own help centre returns zero results for "RESO".

> Machine-to-machine seams (both INBOUND, both gated by a signed relationship): the Digital Feeds Program, in which an approved third-party feed vendor syndicates a paying advertiser's listings over FTP as MITS-format XML whose specification guide is supplied only on request to Feeds@apartments.com; and per-MLS rental-listing syndication opt-in, which requires MLS membership. Neither issues an API key and neither returns data to the caller. Generated by API Evangelist from apis.yml — this file is a faithful summary of a provider that publishes no machine-readable contract.

## APIs

- No public APIs. `apis[]` in apis.yml is deliberately empty rather than inventing a product API from marketing pages.

## Specs

- None. No OpenAPI, AsyncAPI, JSON Schema, GraphQL SDL, Protobuf or OData metadata document exists on any Apartments.com host.

## Do not use

- Third-party scrapers and "Apartments.com API" listings on aggregator and RapidAPI-style sites are not operated by or endorsed by CoStar Group, and aggregator profiles carry no official documentation links. Search summaries asserting an OAuth-secured "Apartments.com Customer API" at https://api.apartments.com/v1 are unsubstantiated — that URL returns HTTP 403 and no first-party page documents it.
